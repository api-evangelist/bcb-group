## API Reference
- [Get Token](https://docs.bcb.group/reference/get-token.md): The api uses Bearer Tokens to authenticate requests
- [Balance](https://docs.bcb.group/reference/accounts-account-balance.md): Get balance for a specific account
- [Accounts](https://docs.bcb.group/reference/accounts-list.md): List Accounts List all bank accounts, custody accounts and wallet accounts
- [Transactions](https://docs.bcb.group/reference/accounts-transactions.md): List Account Transactions
- [Transaction Detail](https://docs.bcb.group/reference/accounts-transaction-detail.md): List details of a transaction within user permissions
- [List Beneficiaries](https://docs.bcb.group/reference/beneficiary-list.md): List all beneficiary bank accounts and wallet accounts.
- [Create Beneficiary](https://docs.bcb.group/reference/beneficiary-create.md): Create a new beneficiary
- [Beneficiaries](https://docs.bcb.group/reference/blinc-beneficiaries.md): Returns an array of BLINC accounts of all BLINC members to which you are currently connected to
- [Members](https://docs.bcb.group/reference/blinc-members.md): Returns a single BLINC account based on the BLINC member BLINC id
- [Payment Status Webhook](https://docs.bcb.group/reference/notifications-payment-status-webhook.md): Webhook to track the status of your payment.
- [Authorise Payment](https://docs.bcb.group/reference/payments-authorise-payment.md): **Each payment type requires a different payload, depending on the requirements of the scheme and currency. Check the examples on the right to see the different supported transfers**
- [List Payments](https://docs.bcb.group/reference/payments-list.md): List the payments for an account
- [Get Payment](https://docs.bcb.group/reference/payments-get-payment-by-id.md): Get the details of a single payment for a given account and transaction id
- [Get Payment By Nonce](https://docs.bcb.group/reference/payments-get-payment-by-nonce.md): Get the details of a single payment for a given account and nonce
- [Reverse Deposit](https://docs.bcb.group/reference/payments-reverse-deposit.md): Reverse a Deposit
- [Approve](https://docs.bcb.group/reference/approve.md): Approve a payment where the beneficiary name does not match the name on the account
- [Cancel](https://docs.bcb.group/reference/cancel.md): Cancel a payment where the beneficiary name does not match the name on the account
- [List Accounts](https://docs.bcb.group/reference/virtual-accounts-all-account-data.md): List all virtual accounts for the given segregated account
- [Make a Payment](https://docs.bcb.group/reference/virtual-accounts-authorise-pyment.md): Sends a payment from the virtual account with the given IBAN
- [Close Virtual Account](https://docs.bcb.group/reference/virtual-accounts-close-virtual-account.md): Closes the virtual account with the given IBAN
- [Create Virtual Account](https://docs.bcb.group/reference/virtual-accounts-create-virtual-account.md): Creates new virtual accounts for the given owners
- [Update Owner Address](https://docs.bcb.group/reference/virtual-accounts-owner-address.md): Updates the owner address for the virtual account with the given IBAN
- [Update Owner Bank Details](https://docs.bcb.group/reference/virtual-accounts-owner-bank-details.md): Updates the owner bank details for the virtual account with the given IBAN
- [Bank Lookup](https://docs.bcb.group/reference/bank-lookup.md): Retrieve the bank code (BIC) of the bank holding an account from its IBAN
